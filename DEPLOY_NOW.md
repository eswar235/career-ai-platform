# 🚀 Deploy to Railway in 5 Minutes

## STEP 1: Go to Railway
👉 **Visit: https://railway.app**

## STEP 2: Sign In with GitHub
- Click "Create Account" or "Sign In"
- Select "Continue with GitHub"
- Authorize Railway

## STEP 3: Create New Project
1. Click **"+ New Project"**
2. Select **"Deploy from GitHub repo"**
3. Search for: **`eswar235/career-ai-platform`**
4. Click **"Deploy"**

## STEP 4: Wait for Auto-Detection
Railway will automatically detect:
- ✅ Python backend (FastAPI)
- ✅ Node.js frontend (Next.js)
- ✅ PostgreSQL database

**Deployment starts automatically (~5-10 minutes)**

## STEP 5: Add Environment Variables
Once deployed, click your project and add these variables:

```
SECRET_KEY=generate-random-string-32-chars
JWT_SECRET_KEY=generate-random-string-32-chars
OPENAI_API_KEY=sk-your-openai-key
SENDGRID_API_KEY=SG-your-sendgrid-key
ENVIRONMENT=production
```

*Other variables are auto-generated by Railway*

## ✅ DONE!

Your live URLs will be:
- **Frontend**: `https://career-ai-platform-xxx.railway.app`
- **Backend API**: `https://career-ai-platform-xxx-api.railway.app`
- **API Docs**: `https://career-ai-platform-xxx-api.railway.app/docs`

## Troubleshooting

**❌ Build Failed?**
- Check Railway logs (click project → Deployments → View logs)
- Common issue: Missing environment variables
- Solution: Add all variables from `.env.railway` file

**❌ Database Connection Error?**
- Wait 2-3 minutes for PostgreSQL to initialize
- Check DATABASE_URL is set correctly
- Railway auto-generates this

**❌ Frontend Not Loading?**
- Clear browser cache (Ctrl+Shift+Delete)
- Check NEXT_PUBLIC_API_URL points to your backend
- Wait 30 seconds for CDN cache to clear
