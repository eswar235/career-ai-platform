# Railway Deployment Guide

## Quick Start (5 minutes)

### Step 1: Go to Railway
Visit: https://railway.app

### Step 2: Sign Up / Log In
- Click "Create Account"
- Select "Continue with GitHub"
- Authorize Railway to access your GitHub

### Step 3: Create New Project
1. Click "New Project"
2. Select "Deploy from GitHub repo"
3. Search for and select: `eswar235/career-ai-platform`
4. Click "Deploy"

### Step 4: Railway Auto-Configuration
Railway will automatically:
- ✅ Detect Python backend
- ✅ Detect Node.js frontend
- ✅ Create PostgreSQL database
- ✅ Set up environment variables
- ✅ Start deployment

### Step 5: Configure Environment Variables
In Railway dashboard, add these variables:

**Critical Variables:**
```
DATABASE_URL=<auto-generated by Railway>
REDIS_URL=<auto-generated by Railway>
SECRET_KEY=<generate a random string>
OPENAI_API_KEY=<your OpenAI key>
SENDGRID_API_KEY=<your SendGrid key>
ENVIRONMENT=production
NEXT_PUBLIC_API_URL=<your-railway-backend-url>
```

### Step 6: Deploy
Click "Deploy" button and wait 3-5 minutes

## Environment Variables Reference

### Database
```
DATABASE_URL=postgresql://user:pass@host:5432/dbname
SQLALCHEMY_DATABASE_URL=postgresql://user:pass@host:5432/dbname
```

### Security
```
SECRET_KEY=<generate-random-32-char-string>
JWT_SECRET_KEY=<generate-random-32-char-string>
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

### API Configuration
```
API_HOST=0.0.0.0
API_PORT=8000
ENVIRONMENT=production
LOG_LEVEL=INFO
```

### Frontend URLs
```
NEXT_PUBLIC_API_URL=https://your-backend-url.railway.app
NEXT_PUBLIC_APP_URL=https://your-frontend-url.railway.app
```

### Third-party Services
```
OPENAI_API_KEY=sk-...
SENDGRID_API_KEY=SG....
```

### CORS
```
ALLOWED_ORIGINS=["https://your-url.railway.app","http://localhost:3000"]
```

## Troubleshooting

### Build Fails
- Check Docker logs in Railway dashboard
- Verify all dependencies in requirements.txt
- Ensure Dockerfile is correct

### Database Connection Error
- Wait for PostgreSQL to initialize (2-3 minutes)
- Check DATABASE_URL is correctly set
- Run migrations manually if needed

### Frontend Not Loading
- Clear browser cache
- Check NEXT_PUBLIC_API_URL points to correct backend
- Verify CORS settings

### API Returning 500 Error
- Check Railway logs
- Verify environment variables are set
- Check database connection

---

## Manual Deployment (if auto-deploy fails)

1. Open Railway dashboard
2. Go to your project
3. Click "Settings" → "Source"
4. Select branch and click "Redeploy"
